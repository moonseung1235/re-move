# ASCEND 설치와 로그인

안드로이드는 Chrome에서 앱 주소를 열고 로그인한 뒤 ‘설치 및 바로가기 만들기 → 설치’를 사용합니다. iPhone·iPad는 Safari 공유 메뉴의 ‘홈 화면에 추가’를 사용합니다. 앱의 설치 안내는 기기에 맞춰 구분합니다.

설치 요청 수락만으로 완료라고 표시하지 않습니다. appinstalled 이벤트 또는 실제 독립 실행 모드에서만 설치 상태를 표시합니다. 설치가 막히면 Chrome의 ‘바로가기 만들기’를 통해 웹페이지로 사용할 수 있습니다.

비공개 Sites 주소의 manifest·아이콘·Service Worker는 로그인하지 않으면 401을 반환합니다. index.html의 manifest 링크에는 같은 출처의 인증 정보를 보내도록 crossorigin="use-credentials"를 지정했습니다. 설치를 위해 앱 접근 권한을 공개로 바꾸지 않았습니다.

배포 주소의 ChatGPT 접속 인증과 앱 회원 로그인은 별개입니다. Supabase 설정이 없으면 기기 내 체험 모드로 열리며 증상 입력부터 시작합니다. 정식 이메일 회원 로그인은 Supabase를 연결한 환경에서 활성화됩니다.

검증: 설치 정보 요청의 인증 옵션, 192/512 PNG 아이콘 실제 크기, Android 안내, 설치 요청과 실제 완료 구분 테스트. 실제 Android 설치 완료는 기기에서 별도 확인해야 합니다.
