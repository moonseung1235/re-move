# 3D 동작 보기

가져온 원본: https://github.com/yuch125/Ascend_masungok

원본 커밋: `2b50040f4e9db27ce3dcd095a4595720cf80f76b`

원본의 `PoseAvatar3D.tsx`, 리타기팅 테스트, `PoseKeyframeReview.tsx`와 `public/models/HUMAN.fbx`를 가져와 현재 ASCEND 화면에 맞게 수정했습니다. 외부 저장소의 전체 UI나 호스팅 설정은 가져오지 않았습니다.

- 카메라: 실시간 관절 오버레이와 함께 오른쪽에 3D 모델을 표시합니다. 상단 3D 아이콘으로 표시를 켜거나 끌 수 있습니다. 가로 화면에서는 영상과 나란히 배치합니다. 월드 좌표는 촬영 후 재생에도 사용합니다.
- 촬영 후: 3D 동작을 기본으로 표시. 영상 / 3D 동작 전환, 재생·탐색·속도 변경, 정면·측면·후면·사선 및 터치 회전·확대.
- 홈: 분석 시작 화면. ‘분석하기’에서 운동 선택 → 촬영으로 연결합니다.
- 내 기록: 최근 촬영의 왼쪽에 영상, 오른쪽에 3D 모델을 나란히 배치. 하나의 재생·탐색 막대로 동일 시점을 재생합니다. 원본 영상이 없어도 남아 있는 관절 좌표로 3D를 재생할 수 있습니다. 운동·좌우 필터에 맞는 기록을 표시하며 피드백 상세의 뷰어도 유지합니다.
- 실제로 설정한 목표 각도가 있을 때만 목표 비교 제공. 비교 모델은 관측 프레임의 각도를 보정한 예시이며, 전문가가 촬영하거나 승인한 정답 동작은 아닙니다.

현재 Pose Landmarker에서 나오는 worldLandmarks를 Worker → 실시간 미리보기 → 녹화 샘플 → 분석 → 저장·재생으로 전달합니다. 얼굴 인덱스 0–10은 영상 좌표와 월드 좌표 모두에서 제거합니다. 목 방향은 어깨·몸통으로 추정하며 얼굴 방향을 측정하지 않습니다. 원본의 Holistic 얼굴·손 모델은 추가하지 않았습니다. 모델 손은 기존 손목·손끝 관절을 따라 움직이며 손가락 개별 움직임은 추적하지 않습니다.

예전 기록에 월드 좌표가 없으면 영상 좌표 기반으로 재구성하며 이를 표시합니다. 관절 정보가 없는 프레임은 추적 공백으로 표시합니다. 전면 카메라의 좌우 반전 상태는 기록에 보관해 영상과 3D 재생에 동일하게 적용합니다.

3D 모듈은 필요할 때 따로 불러옵니다. WebGL 또는 모델 로딩이 실패하면 다시 불러오기 안내를 표시하며 촬영·영상 분석은 계속 사용할 수 있습니다. 실제 휴대폰 카메라와 GPU에서의 성능은 별도 확인이 필요합니다.

## 발 접지와 다리 높이

서 있는 동작이며 최소 한쪽 발이 바닥에 닿는다고 가정합니다. 발뒤꿈치와 발끝 중 낮은 관측 지점을 접촉 후보로 삼고, 양발의 상대 높이를 다리 길이에 맞춰 모델 크기로 환산합니다. 무릎의 굽힘 각도로 공중에 떠 있는지를 판정하지 않습니다. 발이 기울어져도 뒤꿈치 또는 발끝이 바닥에 남아 있으면 접지를 유지합니다. 작은 좌표 흔들림에는 높이 필터와 접지 전환 여유 범위를 적용합니다.

모델의 실제 발 메시에서 발바닥 접촉점을 보정하고, 지지 발의 높이로 골반을 배치한 뒤 양쪽 다리에 각각 2관절 IK를 적용합니다. 관측한 무릎 방향으로 굽히며 뼈 길이와 발의 기울기를 유지합니다. 두 발이 닿은 상태의 비대칭 굽힘도 각각 보정하고, 기존의 골반 높이 제한과 양쪽 보정량 평균은 제거했습니다.

이 높이는 단안 영상의 추정 좌표와 접지 가정에 따른 시각화이며 실제 바닥까지의 거리를 측정한 값은 아닙니다. 발이 가려진 경우에는 보이는 발을 우선하고, 양발 모두 관측되지 않으면 시각적 최저 발바닥을 바닥에 맞춥니다. 점프나 양발이 동시에 뜨는 동작은 이 가정의 대상이 아닙니다.
