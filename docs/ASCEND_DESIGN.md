# ASCEND UI

사용자가 제공한 앱 디자인 4개 화면과 목표 설정·계획·피드백 3개 화면을 기준으로 UI를 교체했습니다. 원본 PDF와 PDF의 인물 사진은 저장소에 포함하지 않았습니다.

- 배경: 연한 노랑 `#fcf0c5`에서 연두 `#dfe9bd`로 이어지는 그라데이션.
- 핵심색: 짙은 초록 `#1e503e`, 목표·각도 강조색 `#e7b637`.
- 카드: 흰 배경, 25px 모서리, 옅은 그림자. 390px PDF 화면을 기준으로 한 320–430px 스마트폰 레이아웃.
- 홈: 가장 최근 실제 영상, 관절 오버레이, 최소·최대 각도와 반복, 분석 결과 진입.
- 기록: 부위 필터·정렬·좌우 필터, 실제 최대 각도 추이, 날짜별 영상 목록.
- 커뮤니티: 전체·팔로잉 필터, 실제 글·영상·좋아요·댓글·공유.
- 더보기: 주간 활동 현황, 증상·활동·계획·닉네임·목표 관리, 원본 보관·내보내기·삭제.
- 목표 설정: 병명 직접 입력, 기기 내 진단서 첨부, 활동·요일·반복·각도 설정.
- 계획: 실제 측정값과 직접 설정한 목표, 요청 메모, 계획 시작.
- 피드백: 같은 운동·좌우·촬영 방향·분석 버전의 실제 과거 기록과 비교.

문서의 78°·168°·8회·3/5일 같은 예시 측정값을 앱의 실제 기록처럼 넣지 않습니다. 이전 기록이 없으면 비교값을 생성하지 않습니다. 계획의 활동·반복·요일·각도는 사용자가 정하며 임상 처방으로 자동 생성하지 않습니다.

기존 IndexedDB 이름과 기록 ID를 유지했습니다. 진단서 파일과 파일명은 이 기기에서만 보관하고 계정 동기화·커뮤니티 공유에서 제외합니다. 목표와 팔로잉은 기존 비공개 설정 저장 경로를 이용합니다.

검증: 목표·진단서 첨부·계획 메모·촬영 진입·기록·커뮤니티의 통합 테스트, 실제 값 비교와 주간 일수 테스트, 진단서 동기화 제외 테스트. 실제 화면 자동 검증은 현재 Chrome 주소를 확인할 수 없어 Computer Use가 중단되어 진행하지 못했습니다.
