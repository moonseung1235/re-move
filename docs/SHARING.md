# 영상 공유

촬영 후 ‘게시물 만들기’, 내 기록의 영상 공유 버튼, 피드백의 ‘커뮤니티에 공유’, 커뮤니티의 글 작성은 모두 같은 `ComposeForm`을 사용합니다. 상단 고정 영역의 ‘업로드’ 버튼은 스크롤되는 폼과 HTML form 속성으로 연결되어 있습니다. 미리보기 크기를 제한해 긴 세로 영상도 작성 화면을 밀어내지 않습니다.

내 기록에서 공유하면 현재 계정의 저장소에서 해당 원본을 읽어 첨부합니다. 분석이 실패한 촬영 원본도 공유할 수 있습니다. 원본이 없는 경우 작성 화면 안에 안내하며, 글·선택한 분석만 공유하거나 직접 파일을 첨부할 수 있습니다. 분석 항목은 기본 비공개이며 사용자가 체크한 항목만 게시합니다.

작성 화면을 여는 것으로 게시되지 않습니다. 사용자가 업로드를 눌러야 처리하며, 빈 게시물·중복 처리 중 제출·20MB 초과 첨부는 막습니다. 창을 닫거나 게시를 완료하면 초안을 비웁니다. 공유는 원본의 사본을 사용하며 개인 촬영 기록은 그대로 보관합니다.

Supabase가 설정된 환경에서는 기존 커뮤니티 저장 API를 사용하며, 로컬 체험 모드에서는 기기의 데모 피드에 저장합니다. 통합 테스트는 로컬 계정의 첨부·게시·원본 보존과 세 가지 진입 경로의 업로드 동작을 검증합니다.
